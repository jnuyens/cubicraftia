# Cubicraftia — Full art catalogue

Exhaustive itemised list of every art asset Cubicraftia could ship across
v1.0 + v1.x + v2.0. Companion to `art-direction-brief.md`, `art-needed-next.md`,
and `model-bible.md`.

**How to read priority columns:**
- 🔴 **v1.0** — locked in DOCS.md, ships in v1.0
- 🟡 **v1.x** — common-sense polish or post-launch content (Phase 999.x backlog)
- 🟢 **v2.0** — major expansion scope, requires new design phase

**Per-item descriptions are 3-8 words** — enough to commission the art
without ambiguity. Full visual style rules in `art-direction-brief.md §1`.

## P. Avatar parts — biome-themed sets (Phase 999.1 progression)

The user-image-12 reference shows ~45 humanoid avatar variants across
9 biome themes. These are the **Phase 999.1 backlog** content — avatar
customisation as gameplay progression. Each is a full-builder mesh
(head + torso + legs + hand accessory) variant.

| Biome | Variant count | Examples |
|---|---|---|
| Savannah | 6 | Safari hat, tribal warrior, ranger, photographer |
| Snow | 4-5 | Parka, ski gear, husky-mascot, fisherman |
| Desert | 5 | Bedouin, princess, blue-turban, brown-ranger, purple-wizard |
| Beach | 5 | Surfer, beachgoer, lifeguard, photographer, sailor |
| Jungle | 5 | Hunter, ranger, tribal-chief, botanist, explorer |
| Ocean | 5 | Captain, pirate, sailor, deep-diver, lighthouse-keeper |
| Underwater | 5 | Diver-suit, scuba, marine biologist, mermaid, Neptune |
| Fantasy | 5 | Wizard, knight, elf-archer, dwarf-warrior, robot |
| Hostile | 5 | Zombie, skeleton, goblin, orc, vampire |

**Total: ~45 avatar variants.** Each is a body+accessory swap; only the
visible mesh + texture differs. Phase 999.1 also defines unlock
mechanism (find/craft/use items in world to earn each variant).

🟢 **v2.0+** — defer until Phase 999.1 design firms up.
