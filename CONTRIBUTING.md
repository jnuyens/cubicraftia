# Contributing to Cubicraftia

Thanks for your interest in contributing. This document covers the licensing terms
for contributions and points you at the fuller workflow docs.

## Licensing

Cubicraftia's effective license is **GPL-3.0-or-later WITH the App Store Distribution
Exception** (see [LICENSING.md](LICENSING.md) for the full explanation).

By submitting a contribution (a pull request, patch, or any other change) to this
project, you agree that your contribution is licensed under the same terms as the
rest of the project: **GPL-3.0-or-later WITH the App Store Distribution Exception**.
This keeps the project's licensing consistent as new contributors join: it is the
mechanism that lets the App Store exception stay valid over time, rather than
requiring every past contributor to be tracked down and asked to re-consent each
time the project's distribution needs change.

If you are not able to agree to this, please do not submit a contribution, or reach
out first to discuss.

## Workflow

This project uses the GSD workflow for repository changes: planning artifacts and
execution context stay in sync with the code. See [CLAUDE.md](CLAUDE.md) for the full
convention and [README.md](README.md#contributing) for the entry-point commands.

For build, test, and environment setup, see [INSTALL.md](INSTALL.md).
