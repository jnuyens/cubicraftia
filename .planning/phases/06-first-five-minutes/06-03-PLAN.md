|----------|-------------|
| title_scene → FriendsClient.is_signed_in() | FriendsClient token is validated server-side; title_scene trusts the local cached result |
| title_scene → DeepLinkHandler (CLI args) | CLI args are untrusted; title_scene delegates validation to DeepLinkHandler._ready() token length check |
| Legal footer → legal_viewer.tscn | No trust boundary — local file open only |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-T1 | Tampering | Deep-link token in title_scene | mitigate | DeepLinkHandler already applied 20-char length check; title_scene calls FriendsClient.redeem_invite() which enforces server-side single-use validation |
| T-06-S2 | Spoofing | Session restore "Continue as" shows wrong username | accept | _cached_username is populated from authenticated GoTrue session; no ability to forge without valid JWT |
| T-06-03 | Information Disclosure | title_scene shows username in "Continue as" button | accept | Username is player-chosen display identifier; intentional visibility |
| T-06-SC | Tampering | No new package installs | accept | No new packages; existing Godot APIs only |
</threat_model>
