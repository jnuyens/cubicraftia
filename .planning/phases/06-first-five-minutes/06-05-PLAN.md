## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| New world name field → ProfanityFilter → WorldSave | User input crosses trust boundary; ProfanityFilter.filter_reject() + WorldSave.create_world() both validate |
| World card context menu → OS.shell_open (Export) | OS.shell_open on the world directory is safe; it opens the file manager, not an arbitrary URL |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-S2 | Spoofing | World name profanity bypass | mitigate | ProfanityFilter.filter_reject() called client-side (UI shows error); WorldSave.create_world() calls it again server-side (Phase 5) — defence in depth. Error label never echoes the rejected string |
| T-06-D1-thumbnail | Denial-of-Service | Thumbnail captures fill user:// storage | mitigate | Only 5 worlds max; 256x144 JPEG at 0.85 quality ≈ 25 KB each; 5 × 25 KB = 125 KB total — negligible |
| T-06-SC | Tampering | No new package installs | accept | No new packages |
</threat_model>
