      - "English" button: on press: `TranslationServer.set_locale("en"); _save_locale_pref("en")`
      - "Nederlands" button: on press: `TranslationServer.set_locale("nl"); _save_locale_pref("nl")`
      - Active locale: 2px accent-yellow border on the active language button (same pattern as avatar part selection)

    `func _save_locale_pref(locale_code: String) -> void:`:
    - Read user://settings.cfg (existing ConfigFile from Phase 1-5)
    - Set [settings] locale = locale_code
    - Save

    `func _load_locale_pref() -> void:` (called in _ready()):
    - Load user://settings.cfg; read [settings] locale (default "en")
    - `TranslationServer.set_locale(loaded_locale)`
    - Update button active states

    `func _on_locale_changed(locale_code: String) -> void:`:
    - After TranslationServer.set_locale(), call `get_tree().root.propagate_notification(NOTIFICATION_TRANSLATION_CHANGED)` to force all visible nodes to update their tr() strings immediately

    The language switcher must work regardless of which scene is active (title, world_select, or in-game) since settings_menu is accessible from all contexts.

    - `ui.settings.locale_nl` → EN: "Nederlands", NL: "Nederlands" (NL is always displayed in its native name)

|----------|-------------|
| locale/nl.po → TranslationServer | PO file is a build artifact; runtime locale data |
| user://settings.cfg locale pref → TranslationServer | Local file; no external input; locale_code validated as "en" or "nl" only |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-L1 | Tampering | locale_code from settings.cfg injection | mitigate | Accept only "en" or "nl" as valid locale codes in _load_locale_pref(); fall back to "en" for any other value |
| T-06-L2 | Information Disclosure | NL translations expose game text to scrapers | accept | All game text is player-facing UI — intentionally public; no PII in translation strings |
| T-06-SC | Tampering | No new package installs | accept | No new packages |
</threat_model>
