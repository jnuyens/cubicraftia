Preload: const Helpers = preload("res://tests/conftest_helpers.gd")

Constants:
- _RES_PNG_REGEX: String = 'res://[^\\s\'"]+\\.png'  (matches any res://...png reference in source text)
- MIN_BYTES: int = 200
- _EXCLUDE_DIRS: Array[String] — exclude "res://tests/", "res://addons/", any path containing "minifigure_animator_demo", "shader_wobble_animator", "quadruped_poc", "animation_demo", "demo_scene"

Single test function: test_no_stub_textures_in_shipped_scenes()
1. Collect files via Helpers.find_tscn_files("res://src") and Helpers.find_gd_files("res://src")
2. Compile RegEx with _RES_PNG_REGEX; use regex.search_all(content) to find all matches in each file
3. For each matched tex_path: call FileAccess.get_size(tex_path); if size < MIN_BYTES (includes -1 for missing), append to failures Array[String] with format: "%s: references %s (%d B)" % [file_path, tex_path, size]
4. assert_eq(failures.size(), 0, "Stub textures found:\n" + "\n".join(failures))

Helper: _is_excluded(path: String) -> bool — checks path.begins_with() for each entry in _EXCLUDE_DIRS; also return true if any of the _EXCLUDE_DIRS fragments appears anywhere in the path (use path.contains(frag) for the demo-scene names that may appear mid-path).
