<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Authenticated user → blocks table | User can only INSERT/DELETE/SELECT rows where they are blocker_uid |
| Authenticated user → reports table | User can only INSERT and SELECT their own reporter_uid rows; no UPDATE/DELETE |
| Authenticated user → parental_consents | User can only SELECT their own child_uid row; all writes are service-role only |
| Trigger → username_change_log | SECURITY DEFINER function writes on behalf of the user; user cannot write directly |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-T1 | Tampering | reports INSERT — forged reporter_uid | mitigate | RLS WITH CHECK (SELECT auth.uid()) = reporter_uid; server rejects forged identity |
| T-05-E1 | Elevation of Privilege | profiles INSERT/UPDATE username = 'admin' | mitigate | check_username_reserved trigger raises EXCEPTION for reserved patterns |
| T-05-SC | Tampering | supabase db push — migration integrity | accept | Migrations are SQL text in git; reviewed via PR diff; no binary package installs |
</threat_model>
