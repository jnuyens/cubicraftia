<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client → Supabase blocks table | Anon key + JWT; RLS enforces blocker_uid = auth.uid() |
| Client → Supabase reports table | Anon key + JWT; RLS enforces reporter_uid = auth.uid() |
| Client → Go signaling /consent/request | Bearer JWT required; child's own token only |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-T1 | Tampering | submit_report — forged reporter_uid | mitigate | RLS WITH CHECK (SELECT auth.uid()) = reporter_uid; client cannot override JWT identity |
| T-05-I1 | Information Disclosure | check_consent_status() exposes consent state | accept | Low risk — child checking their own state is legitimate; RLS prevents cross-user access |
| T-05-DOB | Information Disclosure | Raw DOB sent to Supabase | mitigate | sign_up() computes is_under_13 locally; raw day/month/year never in HTTP body |
| T-05-SC | Tampering | npm/pip/cargo installs | accept | No new packages — pure GDScript using Godot built-ins |
</threat_model>
