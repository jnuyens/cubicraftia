<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| NetworkManager.connection_problem signal → overlay display | Reason string is one of a fixed, whitelisted set (Plan 13-01's `CONNECTION_PROBLEM_REASONS`); the overlay's `_BODY_KEYS` dictionary has no fallback "echo the raw reason string" path, so an unexpected reason value cannot inject arbitrary text into the UI |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-05-01 | Information Disclosure | `blocked` reason copy | mitigate | Copy is a static, pre-authored i18n string containing no reference to block status, verified by an automated substring-absence test, not just presence of the key |
| T-13-05-02 | Tampering | `{host}` interpolation | accept | `SessionRegistry.get_host_uid()` is locally-trusted session state (not raw network input at this layer); worst case is displaying an empty/generic fallback name, never executing or rendering unescaped markup (Label nodes render plain text only) |
</threat_model>
