## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| Peer-reported PROTOCOL_VERSION → SessionRegistry | A peer's self-reported integer, trusted at this layer (host-authoritative rejection happens in Plan 13-04; this plan only prevents an already-accepted peer from ever being electable if inconsistent data exists) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-02-01 | Elevation of Privilege | `compute_elected_host()` | mitigate | Version-mismatched peers are excluded from the candidate set before sorting — a mismatched build can never be elected host, closing the "connect-and-desync via failover promotion" path (D-09) |
| T-13-02-02 | Denial of Service | Empty-candidate-set edge case | mitigate | Explicit fallback to the unfiltered set when filtering would leave zero candidates — election can never deadlock even under corrupted/incomplete version data |
</threat_model>
