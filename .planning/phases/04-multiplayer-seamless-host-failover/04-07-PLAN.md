<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Invite link | Generated by FriendsClient (Supabase call); link contains 26-char token; shared via clipboard or OS share sheet |
| Host admin controls | Kick/Freeze/Roll-back only shown to host (multiplayer.is_server()); peer UI is read-only |
| Roll-back modal | Requires 2-tap confirmation to prevent accidental data loss |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-07-T | Tampering | Non-host triggering kick via UI | mitigate | Players tab shows admin controls only when NetworkManager.is_session_host(); kick_peer RPC decorated @rpc("authority") — only host peer can call it on other peers |
| T-04-07-R | Repudiation | Roll-back without confirmation | mitigate | Roll-back requires 2-step confirmation modal; action logged via push_warning("WorldSave.roll_back by host at %s" ...) |
| T-04-07-I | Information Disclosure | Invite link in clipboard | accept | User explicitly taps "Copy" — deliberate action; clipboard is ephemeral; link expires in 24h |
</threat_model>
