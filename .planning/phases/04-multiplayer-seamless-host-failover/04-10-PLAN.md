```gdscript
func save_world_snapshot(snapshot_id: String) -> bool:
    if _db == null:
        return false
    var inventory_blob := var_to_bytes(Inventory.get_all_state())
    # chunk_blob: Zstd-compressed serialisation of dirty chunks
    # Reuse _save_chunk path — iterate _dirty_chunks and build a blob
    var chunk_dict: Dictionary = {}
    for coord: Vector3i in _dirty_chunks.keys():
        chunk_dict[str(coord)] = _dirty_chunks[coord]  # raw chunk data (bricks)
    var raw_bytes := var_to_bytes(chunk_dict)
    var chunk_blob := raw_bytes  # Zstd compress via same path as checkpoint
    _db.call("query_with_bindings",
        "INSERT OR REPLACE INTO snapshots(snapshot_id, created_at, chunk_blob, inventory_blob) VALUES (?, ?, ?, ?);",
        [snapshot_id, Time.get_unix_time_from_system(), chunk_blob, inventory_blob])
    return true
```

Inventory.reset_from_state implementation:
```gdscript
func reset_from_state(state_blob: PackedByteArray) -> bool:
    if state_blob.is_empty():
        push_warning("Inventory.reset_from_state: empty blob — no-op")
        return false
    var state: Variant = bytes_to_var(state_blob)
    if not (state is Dictionary):
        push_error("Inventory.reset_from_state: invalid blob format")
        return false
    _inventories = state.get("inventories", {}).duplicate(true)
    _next_seq = state.get("next_seq", 0)
    # Rebuild journal from state if present (for replay)
    _journal = state.get("journal", []).duplicate(true)
    # Emit inventory_changed for all builders so UIs refresh
    for builder_id: String in _inventories.keys():
        inventory_changed.emit(builder_id)
    return true
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SNAPSHOT_RESET RPC | @rpc("authority") ensures only the host (peer_id=1) can send a snapshot reset to peers |
| Inventory state blob | var_to_bytes serialisation is deterministic; bytes_to_var on the receiver validates the type before applying |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-10-T | Tampering | Peer forging a SNAPSHOT_RESET | mitigate | @rpc("authority") on _receive_snapshot_reset means only peer_id=1 (host) can invoke it; Godot multiplayer layer enforces this |
| T-04-10-I | Information Disclosure | Inventory blob contains all player items | accept | Inventory blob is sent only to peers who are already in the session (authenticated via WebRTC channel); not broadcast publicly |
| T-04-10-R | Repudiation | Snapshot overwriting valid game state | mitigate | load_latest_snapshot() uses ORDER BY created_at DESC LIMIT 1; snapshots are INSERT OR REPLACE (append-only by unique snapshot_id including timestamp); no snapshot can be backdated |
| T-04-10-P6 | Denial of Service | Host disconnect during snapshot write (Pitfall 6) | mitigate | Existing WorldSave atomic-rename + .bak.1/.bak.2/.bak.3 backup chain protects against partial write; failover snapshot creation is called before old host tears down WebRTC |
</threat_model>
