Keepalive pattern (04-RESEARCH.md Pattern 4, lines 314-335):
```gdscript
const KEEPALIVE_INTERVAL_S := 1.0
const KEEPALIVE_TIMEOUT_S := 6.0
const KEEPALIVE_WARN_THRESHOLD := 3

func _process(delta: float) -> void:
    _keepalive_accum += delta
    if _keepalive_accum >= KEEPALIVE_INTERVAL_S:
        _keepalive_accum = 0.0
        if multiplayer.is_server():
            _send_keepalive_to_all_peers()
        _check_peer_timeouts()

@rpc("authority", "call_remote", "unreliable")
func _keepalive_ping(server_time_us: int) -> void:
    _keepalive_pong.rpc_id(1, server_time_us, Time.get_ticks_usec())

@rpc("any_peer", "call_remote", "unreliable")
func _keepalive_pong(sent_us: int, peer_received_us: int) -> void:
    var peer_id := multiplayer.get_remote_sender_id()
    var rtt_us := Time.get_ticks_usec() - sent_us
    SessionRegistry.update_peer_rtt(peer_id, float(rtt_us) / 1000.0)
    SessionRegistry.reset_keepalive_counter(peer_id)
```

Failover state machine from 04-RESEARCH.md (lines 615-662):
```
IDLE → CONNECTING → CONNECTED_AS_HOST or CONNECTED_AS_PEER
CONNECTED_AS_PEER → keepalive timeout → FAILOVER_DETECTING (200ms election delay)
FAILOVER_DETECTING → if am_elected → FAILOVER_ELECTED, else → FAILOVER_WAITING
FAILOVER_ELECTED → save snapshot → FAILOVER_PROMOTING
FAILOVER_PROMOTING → create_server() → update_host on signaling → wait peers → FAILOVER_COMPLETE
FAILOVER_WAITING → listen for new host → reconnect via signaling → CONNECTED_AS_PEER (new host)
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| WebRTC data channel (peer → host) | Peers send events to host via RPC; host is the authority |
| Signaling WebSocket (client → Go server) | JWT verified by Go server; signaling server never receives game state |
| Keepalive RPC | Unreliable channel; missed keepalives trigger disconnect, not game state changes |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-05-T | Tampering | Fake event injection from peer | mitigate | @rpc("any_peer") _receive_replicated_event checks multiplayer.get_remote_sender_id() — events received from non-1 (non-host) peer are ignored; only host broadcasts events via rpc() |
| T-04-05-T2 | Tampering | Peer impersonates host in RPC | mitigate | Godot @rpc("authority") decorator means only peer_id=1 (the server/host) can call _receive_replicated_event on peers; enforced by Godot multiplayer layer |
