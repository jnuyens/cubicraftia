## Overview

Cubicraftia v1.0 is a Lego-style brick voxel sandbox game shipping on macOS, Windows, Linux, iOS, and Android. Players sign in (email/password + age gate), customise a builder avatar, walk through a 4-step in-world tutorial, and explore an infinite procedurally generated world made of 1m terrain cubes and Lego-style stud-snap bricks (50 brick types × 18-color palette). Multiplayer hosts 1-4 friends over WebRTC P2P with seamless 2-4-second host failover, text chat with profanity filter, and host admin tools (kick / freeze build / roll back). Full UGC safety pipeline: global mutual blocks, 3-surface reporting, parental consent for under-13, EULA + privacy bundled and re-acknowledged on update, store readiness docs for App Store and Play Store.

## Milestone Summary

**Key Decisions:**
- Engine: Godot 4.6 (MIT) — only OSS engine with shipped mobile + voxel ecosystem
- Voxel: Zylann/godot_voxel (MIT) — VoxelMesherBlocky for Lego parts + VoxelMesherCubes for terrain
- Networking: WebRTCMultiplayerPeer (libdatachannel) + Go signaling + coturn TURN; ENet LAN fallback
- Auth: Supabase self-hosted (GoTrue + Postgres + RLS) — friends graph relational, not adjacency-list
- Persistence: SQLite per world via godot-sqlite, Zstd-compressed chunk deltas, 30s snapshots
- Host failover: 6s keepalive → local deterministic election (RTT EWMA + join-order tiebreaker) → latest-snapshot-wins per chunk
- Safety: LDNOOBW CC-BY-4.0 profanity word list (en+nl+fr+es+de bundled), email-plus parental consent (COPPA), CSPRNG single-use 24h invite tokens, base32-128
- License: GPL-3.0-or-later (project) + permissive deps (MIT/Apache-2.0)
- Brand: "Cubicraftia" definitive name; brick/stud/builder vocabulary; no "Lego"/"Minecraft" in player-facing strings
