# Requirements: Cubicraftia — v1.1 Content & Polish

**Defined:** 2026-06-01
**Core Value:** Het Lego-bouwgevoel in een Minecraft-achtige sandbox — alleen of met je vrienden.

## v1.1 Requirements

Requirements for the Content & Polish milestone. Each maps to a roadmap phase. Phase numbering continues from v1.0 (last phase: 6 → v1.1 starts at Phase 7).

### Asset Integration

Wire the already-committed art into live scenes; remove placeholder stubs.

- [x] **ASSET-01**: Player sees the real title-screen background and wordmark on launch (no transparent/placeholder stub)
- [ ] **ASSET-02**: Player sees the 8 real avatar preset thumbnails in the avatar creator
- [x] **ASSET-03**: Player sees a real world thumbnail (per-world or default) in the world-select screen
- [x] **ASSET-04**: Player sees the real FTUE arrow and tutorial storyboard art during the 4-step walkthrough
- [x] **ASSET-05**: Player sees real HUD, toast, and map-marker sprites in-game (no 1×1 stub sprites)
- [ ] **ASSET-06**: Player sees real achievement badges, rarity borders, and biome minimap tiles wherever those surfaces appear
- [x] **ASSET-07**: No 1×1 transparent placeholder asset remains referenced by any shipped scene (verified by audit)

### Creature & Builder Animation

Productionize the three POC rig archetypes into idle + locomotion animation for all entities. Combat/death polish is deferred.

- [x] **ANIM-01**: Soft-body creatures (3 slime tiers, fish, ghost) play idle + movement animation in-world via the shader-wobble system
- [x] **ANIM-02**: Quadruped wildlife play idle + movement animation in-world
- [x] **ANIM-03**: Humanoid hostiles and the builder share a rigid-piece rig that plays idle + walk animation
- [ ] **ANIM-04**: The player's builder visibly animates — idle when still, walk/run when moving — during normal play
- [x] **ANIM-05**: All 5 hostile creature types animate (idle + locomotion) when active in the world
- [x] **ANIM-06**: Animation adds no measurable frame-rate regression versus the v1.0 mobile performance targets

### Localisation Review

Native Dutch validation of v1.0 NL content.

- [x] **LOCALE-01**: The profanity wordlist is reviewed and corrected by a native Dutch speaker in a gaming context
- [x] **LOCALE-02**: The ~478 NL `msgid` translations are reviewed and corrected by a native Dutch speaker
- [~] **LOCALE-03**: The NL locale displays correctly in-game with no untranslated, truncated, or garbled strings (profanity regression tests pass 15/15; in-game visual screenshot pass DEFERRED — hardware-gated, see 09-03-SCREENSHOTS.md)

## Out of Scope

Explicitly excluded from v1.1. Documented to prevent scope creep.

| Feature | Reason |
|---------|--------|
| Audio (music + SFX) | Separate polish track; not part of the visual/animation focus of v1.1 |
| Launch readiness (signing, deploys, attorney) | Operator/legal track, not code/content work; gated on external parties |
| Hardware UAT discharge | Requires physical devices/operators; separate verification milestone |
| Combat/death animation | v1.1 is locomotion-first; combat polish follows once idle+movement ships |
| New gameplay (progression, voice, lobbies, SSO) | Feature expansion, not content/polish; deferred to a gameplay milestone |
