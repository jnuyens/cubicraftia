## Wiring Gaps Closed Inline During Audit

Integration checker found 3 BLOCKERs + 3 WARNINGs. Closed in commit `cc884f5`:

| ID | Issue | Fix |
|----|-------|-----|
| B1 | `NetworkManager.join_blocked` signal had zero subscribers — under-13 unconsented join silently failed | `main_scene._install_parental_gate_wiring()` connects signal → `ParentalGatePanel.show_join_blocked_modal` |
| B2 | `ParentalGatePanel.install_banner()` never called — restricted-account amber banner (Surface F) never mounted | Same method now passes UI CanvasLayer to install_banner |
| B3 | `FriendsClient._blocks_cache` stale until next launch after block_user — NetworkManager._is_blocked_locally missed in-session blocks | `block_modal._on_fc_user_blocked` now calls `FriendsClient.get_blocks()` to refresh cache |
| W1 | `FriendsClient.get_username()` returned "" until first change_username call | `_on_auth_completed` now parses `user_metadata.username` from GoTrue (fallback: email local-part) |
| W2 | `WORLD_LOADED` telemetry fired twice per world load (world_select_screen + main_scene) | Removed from world_select_screen — main_scene emits once at world_ready |
| W3 | Friends panel + chat overlay no mutual exclusion (both can be open) | Deferred — cosmetic only, ContextMenu autoload at layer=25 covers both |
